# Saksham Path - Web Accessibility

**Saksham Path** is a Chrome extension designed to make the web more accessible, readable, and easier to navigate for everyone.

### ✨ Features

- 🔊 **Reading Assistance** – Text Reader, Read Selected, Read Page, Pause/Resume/Stop, and Speed Control
- 🇮🇳 **Indian Language Support** – Extension language and website translation
- 🔍 **Reading Tools** – Reading Guide and Text Magnifier
- 🔤 **Content Adjustments** – Font Size, Line Spacing, Letter Spacing, Word Spacing, and Readable Font
- 🎨 **Color & Contrast** – Grayscale, High Contrast, Dark Contrast, Bright Contrast, and Saturation controls
- 🖱️ **Interaction Tools** – Interactive Elements and Large Cursor
- 💾 **Persistent Settings** – Accessibility preferences are saved locally

### 💡 Why "Saksham Path"?

**Saksham Path** means a *path towards independence*. “Saksham” means **capable and empowered**, reflecting our vision of enabling people with disabilities to access, understand, and navigate the digital world **on their own, without depending on others**.

> **Accessibility should not be about asking for help. It should be about having the ability to do it yourself.**

### 🛠️ Built With

- HTML
- CSS
- JavaScript
- Manifest V3

### 📦 Installation

1. Download the latest release ZIP.
2. Extract the ZIP file.
3. Open `chrome://extensions` in Chrome.
4. Enable **Developer mode**.
5. Click **Load unpacked**.
6. Select the extracted **Saksham Path** folder.
